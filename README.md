Leonida Trophy Guide — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5: official names, descriptions and grades, a checklist saved in your browser, filters by kind and grade, a spoiler setting that hides story trophies until earned, a roadmap to the platinum, missable-trophy flags, and a guide in our own words with its sources for every trophy. No network requests, no server needed.

## Run it

```sh
# Open the guide straight from its files — no build step, no server:
#   app/index.html
# Or serve the app/ folder and open it:
python3 -m http.server 8080 --directory app
```
